# Migrations — Alembic Database Migrations

**Purpose**: Manages PostgreSQL schema evolution for JobIndex.

**Responsibilities**:
- Baseline schema creation (S1)
- Platform seed data (S1)
- Future schema changes (S5, S9, etc.)

**Architecture**:
```
migrations/
├── env.py              # Alembic environment (async, reads JOBINDEX_DATABASE_URL)
├── script.py.mako      # Migration template
└── versions/
    ├── 0001_baseline.py    # S1: 14 enums, 7 tables, all constraints/indexes/triggers/views
    └── 0002_seed_platforms.py  # S1: Seeds platform table from docs/platforms.md
```

**Migration Conventions**:
- **Hand-written DDL** — Not autogenerated; readable against `docs/schema.md`
- **One statement per `op.execute()`** — asyncpg cannot run multiple commands in one prepared statement
- **Explicit naming** — All constraints, indexes, triggers named per `NAMING_CONVENTION`
- **Downgrade safety** — Drops in dependency order (view → triggers → functions → tables → enums)

**S1 Baseline (`0001_baseline.py`)**:
Creates in order:
1. Extensions: `pgcrypto`, `pg_trgm`, `unaccent`
2. 14 Enum types
3. `platform` table + constraints
4. `source` table + constraints + partial index
5. `job` table + constraints + indexes (including generated columns)
6. `job_cluster` table + FK to `job`
7. `ALTER TABLE job ADD CONSTRAINT job_cluster_id_fkey` (resolves circular FK)
8. `job_occurrence` table + constraints + indexes
9. `fetch_run` table + indexes
10. `change_event` table + constraints + indexes
11. Deferred triggers: `first_seen_at` immutability, liveness guards, cluster canonical
12. `job_closure_candidates` view

**Seed Migration (`0002_seed_platforms.py`)**:
- Parses `docs/platforms.md` via `jobindex.platforms.load_platform_rows()`
- Inserts 78 rows with `transport=NULL` (no probe run yet)
- `ON CONFLICT (key) DO NOTHING` for idempotency
- Validates exactly 78 rows

**Commands**:
```bash
# Upgrade to head
alembic upgrade head

# Downgrade to base
alembic downgrade base

# Generate new migration (autogenerate not used for S1 baseline)
alembic revision -m "description"

# Check current revision
alembic current

# Show history
alembic history
```

**Configuration**:
- `alembic.ini` — Script location, logging
- `env.py` reads `JOBINDEX_DATABASE_URL` from `jobindex.settings`
- No committed database URL

**Testing**:
- Migration upgrade/downgrade cycle tested in CI (requires PostgreSQL)
- `tests/db/test_platform_seed.py` verifies seed data row-for-row

**Failure Handling**:
- Migration fails if `docs/platforms.md` doesn't have 78 rows
- Downgrade drops objects in correct dependency order
- `IF EXISTS` / `IF NOT EXISTS` guards for idempotency

**Current Implementation Status**: S1 complete — baseline + seed migrations. S5 adds `source_run_queue`, S9 adds dedup tables.
